# Источники случайных мемов для Telegram-бота

Проверено 16 октября 2026 года. Требуется уже готовая картинка с подписью; «шаблон мема» без текста сам по себе задачу не решает.

| Вариант | Что даёт | Ограничения и пригодность |
| --- | --- | --- |
| [Meme API (D3vd)](https://github.com/D3vd/Meme_Api) | Бесплатный публичный `GET https://meme-api.com/gimme`, возвращает случайный пост Reddit: `url`, `title`, `postLink`, `nsfw`, `spoiler`. Можно выбрать subreddit, например `/gimme/soccermemes`; код на Go открыт под MIT. | Самый простой вариант для прототипа. README не обещает SLA и не публикует лимит запросов. Контент сторонних авторов: MIT покрывает код сервиса, а не права на картинки. Сервис берёт данные Reddit; стабильность зависит и от него, и от Reddit. Фильтровать `nsfw`, `spoiler`, тип картинки, при необходимости заголовок. |
| [Reddit Data API](https://www.reddit.com/dev/api/) напрямую | Можно получить подборку постов нужного subreddit и случайно выбрать подходящее изображение самим. | Нужна OAuth-авторизация. [Правила Reddit](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki) указывают 100 запросов/мин на OAuth client ID для допустимого бесплатного доступа и блокировку трафика без OAuth. Больше контроля, но больше кода и правил хранения/удаления чужого контента. |
| [Imgflip API](https://imgflip.com/api) | Бесплатный `/get_memes` возвращает популярные **шаблоны** с URL картинки; бот может выбрать случайный и добавить собственную подпись через `/caption_image` с API-ключом. | Не возвращает случайные уже опубликованные мемы. Для генерации нужна своя подпись и ключ. Поставщик предупреждает, что пользовательский каталог не курируется полностью; API Premium нужен для поиска и автоматической генерации. [Условия](https://imgflip.com/terms) отдельно регулируют hotlink изображений. |
| Своя коллекция | Ручной набор проверенных мемов в volume/репозитории и случайный выбор; Telegram `file_id` позволяет повторно отправлять уже загруженную картинку. | Максимальная предсказуемость и контроль содержания, но картинки надо собирать и обновлять вручную; соблюдать права авторов. |

## Практическая рекомендация

Для первой версии команды `/meme` использовать [Meme API](https://github.com/D3vd/Meme_Api) и разрешённый тематический subreddit, если нужны футбольные мемы. На ответе проверять `nsfw == false`, `spoiler == false`, URL изображения и MIME/размер; делать несколько попыток, затем понятное сообщение об ошибке. Учитывать повторы по `postLink`, если это важно группе. Публичный API не даёт гарантии доступности; собственная подборка подходит как резерв.

По [Telegram Bot API](https://core.telegram.org/bots/api#sending-files), `sendPhoto` принимает HTTP URL: Telegram сам загружает файл, для URL фото указан предел 5 МБ; при загрузке multipart — 10 МБ. URL должен отдавать корректный MIME. Случайный пост может оказаться GIF/видео или неподходящим WebP; такой пост следует пропустить либо отправлять отдельным методом. Подпись к изображению можно взять из `title`, ссылку на оригинал — из `postLink`.

Сервис Meme API открыт под MIT, но это лицензия программного кода, не лицензия мемов из Reddit. Для публичного или коммерческого распространения нужна отдельная проверка прав на изображения.
